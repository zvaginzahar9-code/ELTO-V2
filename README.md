# ELTO

Сайт ТОО «Энергосистемы ЭЛТО» (Караганда) — завода-производителя опор
освещения, мачт и металлоконструкций.

## Overview

Редизайн действующего сайта elto.kz. Всё содержимое — каталог, характеристики,
новости, контакты — выгружено с оригинала и перенесено дословно: ни одна цифра,
формулировка и фотография не заменены. Изменена подача: сайт собран как
scroll-driven издание, где каталог и технические таблицы остаются спокойной
рабочей поверхностью, а главная страница ведёт по производству кадром.

Дизайн-решения и их обоснование — в [DESIGN-DIRECTION.md](DESIGN-DIRECTION.md).

## Features

- каталог: 268 изделий, 52 раздела, 68 таблиц характеристик, поиск по каталогу;
- карточка изделия: фотографии, чертежи, характеристики, документы, сопутствующая продукция;
- разделы новостей, партнёров, вакансий, фотогалереи и полезной информации;
- страница материала свёрстана как разворот издания: рубрика, крупный заголовок, полосный кадр, читаемая колонка, переход к соседнему материалу;
- страница контактов с интерактивной картой производства (тайлы, перетаскивание, зум, схема/спутник) без сторонних библиотек;
- три языка — RU полностью, KK и EN в том объёме, в каком они есть на оригинале; где перевода нет, показывается русский текст;
- scroll-сцены на главной: подъём вдоль мачты, линия производства, раскрытие каталога, переход фотографии в чертёж, география;
- кадровый скраб последовательностями JPEG вместо `video.currentTime`, с отдельной портретной версией для вертикального экрана;
- адаптив от 320 px, фиксированная навигация со сменой грунта, мобильное меню;
- поддержка `prefers-reduced-motion`: сцены не запускаются, кадры остаются на постерах, счётчики показывают конечные значения;
- изображения в трёх ширинах в webp и avif, ленивая загрузка, заданные пропорции.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** — сборка и dev-сервер
- **React Router** — маршрутизация
- **Anime.js v4** — таймлайны и проявления текста
- **Lenis** — инерционная прокрутка
- **sharp** — конвейер изображений (только сборочные скрипты)
- **playwright-core** — визуальный контроль и проверки (только сборочные скрипты)

Без GSAP и Three.js — ни одна сцена их не потребовала.

## Notes

**Пересборка данных и медиа.** Контент и изображения уже собраны и лежат в
репозитории — для запуска ничего пересобирать не нужно. Командам ниже нужны
исходники в `_source/photos` и `media-src`, которые в репозиторий не входят
из-за объёма.

| Команда | Что делает |
|---|---|
| `npm run data` | `_source/content-all.json` → `src/data/*.json` и `public/data/**` |
| `npm run images` | `_source/photos/*` → `public/img/{400,900,1600}/*.{webp,avif}` |
| `npm run media` | `media-src/*.mp4` → `public/media`, `public/seq`, `src/data/media.json` |
| `npm run fonts` | забирает woff2 у Google Fonts → `public/fonts` и `src/styles/fonts.css` |
| `npm run shoot` | снимает сайт в настоящем браузере для визуального контроля |

**Проверки.** Запускаются по работающему серверу (`npm run dev` или
`npm run preview`); адрес переопределяется переменной `SITE_URL`.

| Команда | Что проверяет |
|---|---|
| `npm run check` | линт, типы, сборка |
| `npm run qa` | всё перечисленное ниже подряд |
| `npm run qa:responsive` | тринадцать ширин от 320 до 2560: горизонтальная прокрутка, элементы за краем, цели нажатия, ошибки консоли и сети |
| `npm run qa:overlap` | налезания: сравнивает рамки видимого текста с учётом прозрачности предков и обрезки масками |
| `npm run qa:a11y` | режим «меньше движения», alt, доступные имена, видимость фокуса |
| `npm run qa:scroll` | плавность: время кадра во время прокрутки всей главной |
| `npm run qa:perf` | вес первой загрузки, FCP, число узлов — отдельно для десктопа и телефона |
| `npm run qa:vitals` | живые FCP, LCP, CLS в браузере: какой элемент дал LCP и что сдвинуло раскладку |
| `npm run qa:lighthouse` | Lighthouse по медиане нескольких прогонов (`--desktop`, `--runs`, `--path`) |
| `npm run qa:headers` | поднимает `dist` с заголовками из `vercel.json` и ищет нарушения CSP |

**Первый кадр без ожидания.** Сайт рисуется на клиенте, поэтому до выполнения
бандла показывать нечего. Чтобы телефон не смотрел в пустой экран, в
`index.html` лежит стартовый кадр — графит и знак ровно на месте героя, со
встроенными стилями и встроенным SVG. Отдельного запроса он не делает, и
первая отрисовка укладывается в тот же круг по сети, что и сам документ.
Стили приложения сборка тоже кладёт внутрь документа (плагин в
`vite.config.ts`): отдельный файл стилей блокировал бы отрисовку на целый
круг. Шрифты лежат на своём домене — ссылка на Google Fonts стоила ещё двух
соединений до первого пикселя.

**Заголовки и кэш.** `vercel.json` держит CSP, защиту от кликджекинга,
`nosniff`, политику реферера и HSTS, а статике с хэшем в имени выдаёт
годовой неизменяемый кэш. Политика проверяется на собранном сайте
командой `npm run qa:headers`.

**Один тактовый генератор.** `src/motion/clock.ts` крутит единственный
`requestAnimationFrame`, в котором по очереди обновляются Lenis, движок
anime.js (`engine.useDefaultMainLoop = false`) и scroll-сцены. Поэтому
кадровый скраб, таймлайны и прокрутка не могут разойтись на кадр.

**Сцены вместо триггеров.** `src/motion/scene.ts` — реестр отрезков документа:
сцена получает свой прогресс `0→1`, и позиция `0.34` всегда значит «34 %
сцены». Закрепление кадра сделано на `position: sticky`, а не программным
пином — дешевле и без пересчёта раскладки.

**Скраб кадрами, а не видео.** `video.currentTime` по скроллу заикается на
длинном GOP. `src/components/motion/ScrollSequence.tsx` рисует декодированные
JPEG в канвас: один `drawImage` на сменившийся кадр, без seek. До загрузки
кадров и навсегда, если рендера нет, кадр держит постер.

**Вертикальная версия сцены.** Кадр 16:9 на экране 9:16 обрезается до четверти
ширины. Поэтому у героя есть отдельная портретная версия того же объекта при
том же свете, и `ScrollSequence` выбирает дорожку по ширине и повороту экрана.

**Происхождение медиа.** Кинематографичные кадры среды — индустриальное небо,
искры плазмы, ванна цинкования, ночная трасса — сгенерированы. Продукция в
кадре и все изображения каталога — настоящие фотографии и чертежи ELTO.

**Фирменная гамма.** Зелёный `#85C227` взят из логотипа, остальные акценты — из
темы оригинала. Сайт живёт на двух грунтах: графит для кинематографичных сцен,
бумага для каталога и характеристик.
